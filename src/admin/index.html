Content is managed with Decap CMS, configured in src/admin/config.yml.

To edit content on your own computer, open Terminal in the project folder and run:

npm run cms
  1. Local CMS backend starts via decap-server
  2. Site preview at localhost:8080
  3. Saving writes Markdown and JSON straight into src/; commit and push to publish

Editing live from this page needs the GitHub backend to be switched on in config.yml. Until then, use the local workflow above.
